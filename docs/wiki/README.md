## 신뢰도와 사용 원칙

1. 공식 계약을 가장 먼저 확인한다.
2. `15_*`~`19_*`는 공식 스펙 공개 후 작성한 실무 자료다.
3. `01_*`~`13_*`는 스펙 공개 전 조사이므로 모델명, API와 도구 가정을 재검증한다.
4. 외부 출처의 주장과 대회 런타임에서 직접 확인한 사실을 구분한다.
5. 구현 판단은 [Engineering Playbook](../engineering/playbook.md), 실제 후보 비교는
   [평가 기록](../evaluations/README.md)을 함께 본다.
