## 강점

- 평가한 모든 요청에 정상 응답했다.
- 평균 모델 지연이 D2보다 약 19.57초 짧다.
- communication과 instruction following 표본에서 rubric을 안정적으로
  충족했다.
- health data task처럼 구조화된 요청에서 강한 결과를 냈다.

## 약점과 위험

- context seeking이 음수다. 정보가 부족한 상황에서도 확인 질문 없이 답을
  확정하거나, 필요한 환자 맥락을 충분히 수집하지 않을 가능성이 있다.
- global health 두 표본이 57.14점과 17.86점으로 편차가 크다.
- 빠른 종료 정책이 불필요한 검색뿐 아니라 필요한 검색과 확인 질문까지
  생략할 수 있다.

## 개선 제안

1. retrieval 여부와 별도로 답변에 필요한 환자 맥락이 충분한지 판정한다.
2. 나이, 증상 기간, 중증도, 동반 질환처럼 안전성에 영향을 주는 정보가
   없으면 짧은 확인 질문을 우선한다.
3. U1의 빠른 종료 조건은 유지하되 context-seeking gate를 추가한다.
4. global health 실패 표본을 회귀 테스트로 고정한다.

## 판정

U1은 현재 **속도 기준 우세 후보**다. 단, context seeking 실패가 반복되는지
30개 이상의 표본에서 확인하기 전에는 최종 후보로 확정하지 않는다.
