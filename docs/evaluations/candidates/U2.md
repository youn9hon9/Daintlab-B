# U2 평가 피드백

## 버전 정의

U2는 원격 Lunit 커밋 `4c6469a`의 context-aware HealthBench 응답 개선을
`dev`에 적용한 모델이다. `dev` 적용 커밋은 `2b3bdcc`다.

- 결과 파일: `eval/results/conquer_val-8-20260821-104519.json`
- 데이터: 공개 `conquer_val` 층화 표본 8개
- seed: `0`
- judge: `gpt-4.1`
- 로컬 프록시 점수: **51.07점**
- 성공률: **8/8**
- 평균 모델 지연: **29.23초**
- 평균 judge 지연: **3.30초**
- 전체 평가 시간: **158.88초**

## 강점

- 평가한 모든 요청에 정상 응답했다.
- 세 후보 중 평균 모델 지연이 가장 짧다.
- U1 대비 completeness가 약 10.87점 개선됐다.
- 전체 실행 시간이 약 159초로 반복 평가에 유리하다.

## 약점과 위험

- context seeking이 여전히 음수라 U1의 핵심 약점을 해결하지 못했다.
- 변경 목적과 달리 context awareness가 U1보다 낮다.
- instruction following이 40점으로 크게 하락했다.
- 정확성, communication, health data task도 U1보다 약해졌다.
- 8개 표본이므로 단일 실행만으로 확정할 수 없지만, 현재 결과로는 U1을
  대체할 근거가 부족하다.

## 개선 제안

1. U2 generation prompt에서 추가된 문맥 추론 지시가 사용자 지시보다 우선되는
   부분이 있는지 점검한다.
2. 답변 전 context-aware 확장보다 사용자 질문의 직접 요구사항을 먼저
   체크하도록 순서를 바꾼다.
3. 확인이 필요한 정보가 없을 때 추론으로 채우지 말고 짧은 확인 질문을 한다.
4. context seeking 및 instruction-following 실패 표본을 고정 회귀 테스트로
   사용한다.
5. prompt 수정 후 동일 8개를 반복하되, 승격 전에는 30개 이상으로 확대한다.

## 판정

U2는 **속도 최우선 후보**지만 현재 품질 기준으로는 승격 보류다. U1의 속도를
조금 개선한 대신 정확성·문맥 인식·지시 준수가 함께 하락했다. 다음 후보는
U1을 기준으로 context-seeking 조건만 제한적으로 보강하는 편이 안전하다.

## 테스트 메모

U2 관련 driver 테스트와 평가기 테스트는 통과했다. 전체 테스트에서는
U2와 무관한 구형 `tests/test_app.py`가 현재 개발 의존성에 없는 FastAPI를
import하여 1건의 수집 실패가 발생했다. 제출 API의 현재 계약 테스트는
통과했다.
