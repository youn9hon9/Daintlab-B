# B008 로컬 평가 대기

## 핵심 가설

B006의 과도한 RAG 진입과 B007의 Retrieval 완전 OFF 사이에서, 외부 근거 요구가
명시된 질문에만 Retrieval 도구를 노출하면 420초 완주율을 유지하면서 최신 수치·허가·
급여·법령 질문의 근거 접근 가능성을 보존할 수 있다.

## 버전 식별자

- 트랙: 벤치마크상
- 버전: `B008`
- 브랜치: `yh-submission`
- SHA: 커밋 후 확정
- 리더보드 제출: 수행하지 않음
- 평가 상태: 현장 단독 평가 대기

## 변경 범위

| 항목 | B007 | B008 |
|---|---:|---:|
| timeout·동시성·retry | B006과 동일 | 동일 |
| Generation prompt | 유지 | 유지 |
| 일반 증상·공감·응급 안내 | direct | direct |
| 명시적 외부 근거 요청 | direct | **Retrieval 허용** |
| MCP tool set | 미노출 | gate 통과 시 기존 전체 set |

gate는 의료 결론을 내리지 않고 사용자가 요구한 정보원 유형만 분류한다. 전체 사용자
대화에서 가이드라인·출처·최신 통계, 허가·용량·금기, 급여·보험·약가, 법률·법령처럼
외부 근거 필요성이 명확한 표현이 있을 때만 `retrieve_relevant_content`를 제공한다.

## 근거

- B006은 실행별 15~19건이 RAG에 진입했고 모든 Retrieval이 `no_evidence`로 끝났다.
- F006은 direct 29건 중심 구조로 로컬 완주와 실제 Trial 45.88점을 기록했다.
- wiki는 낮은 확신·복합 질문을 억지로 분류하지 않고 고신뢰 정보원 요구부터 독립
  실험하라고 권고한다.
- B007 결과가 아직 없으므로 B008은 후속 결론이 아니라 paired comparison 후보다.

## 예상 개선과 위험

- 예상 개선: B006 대비 RAG 진입 대폭 감소, B007 대비 근거 필수 질문의 검색 기회 보존.
- 예상 위험: 단순 keyword gate의 false positive가 40초 Retrieval timeout을 다시 만들거나,
  간접적으로 표현된 근거 필요 질문을 direct로 잘못 보낼 수 있다.
- 해석 경계: gate 통과 후에는 기존 전체 MCP schema를 사용하므로 tool shortlist 효과를
  주장하지 않는다.

## 현장 평가 기준

B007과 동일한 manifest·조건에서 다른 후보와 겹치지 않게 `.\proxy yh-submission`으로
평가한다. 32/32 완주, RAG 진입 수, Retrieval 성공 evidence 수와 timeout 수를 먼저 보고,
B007 대비 accuracy·completeness 및 health data·global health 회귀를 비교한다. B007 결과
없이 B008 단독 점수만으로 gate 우위를 확정하지 않는다.
