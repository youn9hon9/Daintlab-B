# D2 평가 피드백

## 버전 정의

D2는 커밋 `b7fd99b`의 retrieval latency 및 limit 최적화 모델이다.

- 결과 파일: `eval/results/conquer_val-8-20260821-103209.json`
- 데이터: 공개 `conquer_val` 층화 표본 8개
- seed: `0`
- judge: `gpt-4.1`
- 로컬 프록시 점수: **60.45점**
- 성공률: **8/8**
- 평균 모델 지연: **51.88초**
- 평균 judge 지연: **3.53초**
- 전체 평가 시간: **216.01초**

## 평가 축

| 축 | 점수 |
|---|---:|
| Accuracy | 61.47 |
| Completeness | 60.62 |
| Context awareness | 62.34 |
| Communication quality | 89.29 |
| Instruction following | 50.00 |

D2는 U1보다 completeness와 context awareness가 높다. 반면 accuracy,
communication quality, instruction following과 속도는 U1보다 낮다.

## 강점

- U1에서 음수였던 context seeking을 30.95점으로 개선했다.
- 복합 응답 표본에서 모든 rubric을 충족했다.
- 주어진 문맥을 활용하고 필요한 내용을 넓게 다루는 경향이 강하다.
- 로컬 총점은 U1보다 4.14점 높았다.

## 약점과 위험

- 평균 모델 지연이 U1보다 약 60.6% 길다.
- instruction following이 50점으로 낮아, 검색과 상세화 과정에서 사용자의
  핵심 요구를 놓칠 수 있다.
- communication과 hedging이 U1보다 크게 낮다. 답변이 장황해지거나 불확실성
  표현이 부적절할 가능성을 점검해야 한다.
- 동일 계열의 앞선 실행은 약 56.75점이었다. 8개 표본과 judge 비결정성을
  고려하면 이번 60.45점을 안정적인 우위로 단정할 수 없다.

## 개선 제안

1. D2의 context-seeking 판단과 문맥 충분성 검사는 유지한다.
2. 최종 생성 전에 사용자 지시를 다시 대조하는 짧은 self-check를 추가한다.
3. retrieval 종료 조건을 U1 수준으로 단축해 불필요한 모델/MCP 왕복을 줄인다.
4. 답변 길이 자체보다 핵심 질문에 대한 직접 응답, 안전 안내, 불확실성 표현을
   우선한다.
5. instruction-following과 communication 실패 표본을 회귀 테스트로 고정한다.

## 판정

D2는 현재 **로컬 품질 점수 기준 우세 후보**지만 속도와 지시 준수에 위험이
있다. 최소 3회 반복 평가와 30개 이상 확장 평가에서 평균 우위를 확인한 뒤
승격해야 한다.

## 보안 메모

D2 원본 커밋의 Dockerfile에는 API 키가 이미지 환경변수로 포함된 이력이
있다. 평가에서는 그 이미지를 실행하지 않고 삭제한 뒤, 비밀키 없는
Dockerfile로 D2 모델 코드만 패키징했다. 해당 값이 실제 자격증명이었다면
폐기 및 재발급이 필요하다.
