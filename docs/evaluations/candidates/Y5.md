# Y5 개발 피드백 — 평가 대기

## 버전과 가설

Y5는 `yh-submission`에서 Y3의 `response_guidance`를 폐기해 Y2 응답 동작으로
돌아가고, Retrieval L2의 입력 schema만 제한적으로 줄이는 후보이다.

- 기준선: Y2 54.68점, 16/16 성공
- 폐기: Y3 guidance payload와 관련 prompt 규칙
- 단일 행동 변경: 고신뢰 법령 질문의 MCP tool-family filtering
- 평가 상태: 현장 랩탑 HealthBench/CoEval 대기

현장 실행명 `Y4`의 38.86점 결과는 실제로 `yh-submission@2b83711`, 즉 Y3와
동일한 모델을 재측정한 것이다. 계획된 `yh-submission2@44141fd` Y4 최적화는 평가되지
않았다. Y3 동일 모델은 두 번의 실행에서 44.30점과 38.86점을 기록해 모두 Y2보다
낮았으므로, Y5에서는 해당 guidance를 재사용하지 않는다.

## 변경 범위

법률·법령·조문·의료법·약사법처럼 정보원 종류가 명확한 query에서는
`openapi_law_search`, `openapi_law_list_articles`, `openapi_law_get_article`만
Retrieval L2에 제공한다. 일반 의료·가이드라인·복합 질문은 Y2와 동일하게 전체 MCP
도구를 제공한다. 서버에 예상한 법령 도구가 하나도 없으면 전체 도구로 fallback한다.

선택 family, 제공 tool 수, schema 문자 수와 전체 tool 수를 로그로 남긴다. 의료 결론,
timeout, retrieval round, citation repair와 evidence budget은 Y2 값을 유지한다.

## 의도적으로 하지 않은 것

- Y3 response guidance 유지
- Y4 keyword retrieval gate와 timeout 축소
- citation repair 제거
- 여러 tool family를 한꺼번에 분류
- 애매한 질문의 강제 routing

## 승격 기준

1. Y2와 같은 representative 16개 manifest에서 16/16 성공한다.
2. 점수가 Y2 54.68점에서 3점 넘게 하락하지 않는다.
3. 법령 표본의 retrieval schema 문자 수와 지연이 감소한다.
4. 법령 citation 성공률이 하락하지 않는다.
5. 전체 fallback 표본의 동작과 품질이 Y2 수준을 유지한다.

Y5가 유효하면 다음 후보에서 별도의 고신뢰 family 하나만 추가한다. 실패하면 filtering을
폐기하고 계측 결과만 보존한다.
