| 평가 | 점수 |
|---|---:|
| 실제 비공개 리더보드 | **38.32** |

새 로컬 점수는 실제 점수보다 10.90점 높다. 과거 Consensus 5개 평가가
86점대로 약 48점 과대평가했던 것과 비교하면 실제 대회에 훨씬 가까워졌지만,
여전히 낙관적인 편향이 남아 있다.

- 결과 파일: `eval/results/D1-representative-conquer_val-32-20260821-111535.json`

- 생성 동시성: `2`, judge 동시성: `8`
- 성공: 32/32
- inference 실패: 0, judge 실패: 0

실제 38.32점은 로컬 95% 신뢰구간 하한보다 1.91점 낮다. 이 신뢰구간은
32개 표본의 sampling uncertainty만 주로 나타내며, 비공개 데이터와 실제
judge 차이에서 생기는 systematic bias는 포함하지 않는다.

## 강점

- 32개 요청과 judge 판정이 모두 정상 완료됐다.
- instruction following과 communication은 다른 축보다 상대적으로 안정적이다.
- 실제 리더보드 점수가 있어 로컬 프록시 편향을 측정할 기준점 역할을 한다.

## 개선 방향

1. 답변 전 환자 나이, 증상 기간, 중증도, 동반 질환, 복용 약물을 구조화한다.
2. 정보가 부족하면 추론으로 채우지 않고 안전에 필요한 확인 질문을 한다.
3. 국가, 의료 접근성, 비용, 이용 가능한 시설을 확인한다.
4. 직접 답변, 이유, 다음 행동, 긴급 위험 신호, 불확실성 중 필요한 항목이
   누락되지 않았는지 최종 생성 전에 확인한다.
5. 검색이 불필요한 일반 상담은 direct path로 종료하고, 검색 후에는 원래
   질문과 환자 맥락을 최종 generation prompt에 다시 명시한다.

## 프록시 해석 원칙

- D1의 실제·로컬 차이 10.90점을 다른 후보 점수에서 일괄 차감하지 않는다.
- U1, D2, U2의 기존 `balanced 8`과 D1의 `representative 32`를 직접 순위
  비교하지 않는다.
- 후보 비교는 동일 prompt manifest, sampling, judge, 동시성으로 수행한다.
- 점수 차이가 작으면 3회 반복 평균과 신뢰구간으로 판단한다.

## 판정

D1은 실제 리더보드 기준점이지만 품질과 속도 모두 개선 여지가 크다. 새
프록시는 과거 방식보다 현실에 가까워졌으나 여전히 약 11점 낙관적이다.
후속 후보에서는 총점 외에도 context awareness와 global health 실패가 실제로
개선되는지를 우선 확인한다.
