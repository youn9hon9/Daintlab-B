# Y4 개발 피드백

## 버전 정의

Y4는 Y3의 응답 품질 보강을 유지하면서, 비용이 큰 경로를 필요한 질문에만 열고
실패 시 추가 생성 호출을 만들지 않는 지연시간 최적화 후보이다.

- 개발 브랜치: `yh-submission2`
- 기반 커밋: `e59ec07`
- 평가 상태: 현장 랩탑 HealthBench/CoEval 프록시 대기

`yh-submission2`는 Y4 전용 브랜치가 아니다. 집컴에서 다음 방법론 후보를 계속
개발하는 재사용 브랜치이며, Y4·Y5 같은 후보 구분은 이 디렉터리의 문서와 커밋으로
관리한다. 검증된 변경만 안정 브랜치인 `yh-submission`에 반영한다.

## 핵심 전략

### Retrieval 입구 제한

가이드라인, 근거·출처, 최신 정보, 약물 용량·금기·상호작용·허가·안전성,
보험·급여·법률처럼 외부 근거가 필요한 질문에만 retrieval tool을 제공한다.
일반 증상 설명, 생활 관리와 공감 질문은 tool 선택 가능성 자체를 제거해 L2 한 번으로
완료한다. 전체 대화에서 조건을 찾으므로 후속 질문에서도 앞선 근거 요구를 보존한다.

### Citation 재생성 제거

존재하지 않는 citation은 규칙으로 제거하고 로그에 남긴다. 인용이 빠졌더라도 별도의
L2 교정 호출은 하지 않는다. 답변 내용과 안전 권고를 다시 생성하면서 생길 수 있는
지연과 회귀를 버리는 대신, 인용 완전성 저하 가능성을 현장 평가에서 측정한다.

### 예산 축소

| 항목 | Y3 | Y4 |
|---|---:|---:|
| 요청 전체 예산 | 170초 | 120초 |
| upstream timeout | 75초 | 50초 |
| retrieval 예산 | 65초 | 40초 |
| 최종 생성 예약 | 75초 | 50초 |
| MCP timeout | 25초 | 18초 |
| retrieval L2 round | 5회 | 4회 |
| MCP call | 3회 | 2회 |
| retrieval context | 20,000자 | 12,000자 |
| evidence | 16,000자 | 10,000자 |

직접 응답은 L2 1회, retrieval 응답은 초기 판단과 최종 생성을 제외하고 retrieval L2
최대 4회·MCP 최대 2회로 제한한다. citation 교정용 추가 L2 호출은 없다.

## 의도적으로 버린 것

- 모든 질문에서 L2가 retrieval 여부를 자유롭게 선택하는 경로
- 잘못된 citation을 고치기 위한 두 번째 최종 생성
- 드물게 쓰이는 세 번째 MCP 호출과 다섯 번째 retrieval round
- 긴 원문을 그대로 모델에 전달하는 context 여유분

## 로컬 검증

- 전체 단위·회귀 테스트: **65/65 성공**
- retrieval gate 직접 테스트: **5/5 성공**
- 일반 질문에서 tool 미제공 및 citation 교정 호출 제거: 성공
- 외부 Lunit API를 사용하는 품질·지연 점수: 미실행

## 현장 평가와 승격 기준

1. Y3와 같은 representative 16개 manifest로 성공률, 점수와 지연시간을 비교한다.
2. 성공률 100%를 유지하고 평균 지연시간을 Y3보다 최소 20% 줄인다.
3. 전체 점수 하락은 3점 이내여야 하며 emergency referral은 하락하지 않아야 한다.
4. 약물 용량·금기, 최신 guideline, 보험·법률 표본에서 retrieval 누락이 없어야 한다.
5. 근거가 필요한 답변의 citation 완전성이 눈에 띄게 하락하면 재생성 대신 routing 또는
   최종 prompt를 수정한다.

## 알려진 위험

- 키워드 기반 gate의 false negative이면 필요한 retrieval을 시작할 수 없다.
- citation 누락을 재생성하지 않으므로 인용 완전성이 Y3보다 낮아질 수 있다.
- 축소된 round와 context 때문에 복합 근거 질문의 recall이 낮아질 수 있다.

Y4는 위 위험을 감수하더라도 전체 요청의 긴 꼬리 지연을 줄이는 실험이다. 현장 결과가
승격 기준을 충족하지 못하면 Y3를 유지한다.
