## 버전 정의

Y3는 Y2의 완주 안정성, citation 검증과 응급 risk flag를 유지하면서 로컬 프록시에서
낮았던 context awareness, completeness, global health를 보강하는 후보이다.

- 기반 커밋: `a1d22dcfe9481483428d4a85b2ee7d3b926d6e55`
- 평가 상태: 현장 랩탑 HealthBench/CoEval 프록시 대기

## 변경 내용

### Context-seeking guidance

전체 user history에서 증상 기간, 중증도·경과, 연령대, 관련 질환·복용약 정보를
확인한다. 개인화된 증상·복약 질문에 안전 판단을 바꿀 정보가 없으면 L2에
`clarification_needed`와 `missing_context` flag를 전달한다.

규칙은 답변 문장을 만들지 않는다. L2는 안전하게 제공 가능한 임시 안내에 먼저
답한 뒤 핵심 질문을 1~2개만 묻는다. 이전 turn에 이미 나온 정보는 다시 요구하지
않는다.

### 응급 우선순위

기존 `risk_flags`가 활성화되면 clarification gate를 끈다. 누락 정보가 있더라도 응급
행동 지침을 먼저 제공하고 질문 때문에 병원·응급실 권고가 늦어지지 않게 한다.

### Instruction following

Generation prompt에 최신 user 메시지의 명시적 요청, 형식과 범위를 먼저 직접
처리하도록 명시했다. 맥락 보강이 사용자가 묻지 않은 긴 감별 목록이나 일반론으로
확장되지 않게 제한한다.

### Global health

비용, 보험, 급여, 이용 가능성과 진료 경로 질문에 국가·지역 정보가 없으면
`global_context_needed` flag를 전달한다. L2는 관할을 질문하거나 가정을 노출해야
하며 한 국가의 의료체계를 보편적인 사실처럼 단정하지 않는다.

## 로컬 검증

- 전체 단위·회귀 테스트: **60/60 성공**
- 새 guidance 테스트: **6/6 성공**
- 기존 멀티턴 응급 flag 회귀: 성공
- 외부 Lunit API를 사용하는 품질 점수: 미실행

## 현장 평가 승격 기준

1. representative 16개를 Y2와 동일 manifest로 실행한다.
2. 성공률 100%와 Y2의 지연 안정성을 유지한다.
3. Context awareness와 completeness가 함께 개선되는지 확인한다.
4. Instruction following이 하락하면 prompt 변경을 승격하지 않는다.
5. Emergency referrals와 global health 주제 점수를 별도로 비교한다.
