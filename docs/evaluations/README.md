# 평가 기록

커밋, 표본, 성공률, 지연 시간과 해석상의 제한을 함께 기록한다.

## 해석 규칙

- 같은 manifest와 실행 조건을 사용한 기록만 직접 비교한다.
- 점수와 함께 inference 성공률 및 지연 시간을 본다.
- 8개 소표본 결과는 방향 탐색용이며 대표 점수로 사용하지 않는다.
- 결과 JSON은 비밀정보나 대용량 산출물을 Git에 넣지 않고 문서에 경로와 요약만 남긴다.
