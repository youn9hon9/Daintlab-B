# 평가 결과 JSON

현장 로컬 프록시가 생성한 구조화 결과를 후보 버전별로 보관한다. 각 파일은
`<버전>.json` 이름을 사용하며 같은 버전의 피드백 문서와 함께 `dev`에 커밋한다.

결과 JSON에는 다음 정보가 포함된다.

- 평가 버전, 브랜치 SHA와 모델 식별자
- dataset, sampling, seed와 표본 manifest hash
- 성공률, 점수, 신뢰구간과 지연
- prompt ID, 주제, 문항별 점수와 실패 상태

원문 prompt, 모델 응답, rubric 본문, API 키는 포함하지 않는다. 이 조건을 만족하지
않는 임시 결과나 상세 서버 로그는 이 디렉터리에 커밋하지 않는다.

`proxy` 명령은 평가가 성공하면 `eval/results/<버전>/`의 원본 결과를 이 디렉터리의
`<버전>.json`으로 자동 복사한다. 에이전트는 내용을 검토한 후 Markdown 피드백과
JSON을 함께 커밋한다.
